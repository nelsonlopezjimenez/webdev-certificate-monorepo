# Recipe App

The goal of the recipe application is to study the provided code that allows to display all recipes, add a new recipe, and display just one recipe. You will implement the function update a recipe and delete a recipe. You can keep the style of the app, or improve it. You may use tailwind with utility classes to apply new styles. You will focus on the client side with vite and react. You need to make sure that the backend server is completely functional (support all CRUD operations) before attempting to connect the client side with the backend server and mongo database. As a challenge, you should be able to search the recipes by their names (extension option: by name or ingredients)
