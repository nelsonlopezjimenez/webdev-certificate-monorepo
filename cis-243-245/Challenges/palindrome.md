A palindrome is string or sequence of characters that reads the same backward as forward.

madam 
nurses run
A Santa Lived As a Devil At NASA (8 words, 25 letters) 
Madam, I am Adam

1) Problem :

    Write a JavaScript function that checks whether a passed string is palindrome or not.

    The input should look like: 
         check_Palindrome('madam'); 
         check_Palindrome('nurses run'); 
         check_Palindrome('fox');
    The output should look like:

         The entry is a palindrome.
         The entry is a palindrome.
         Entry is not a palindrome.

1. Create a "challenges" folder at the root of your repo. Name your JavaScript file as "palindrome.js".
