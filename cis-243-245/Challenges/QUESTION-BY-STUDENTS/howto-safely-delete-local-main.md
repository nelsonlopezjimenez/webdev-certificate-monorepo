# howto safely delete your local main branch in Git

Deleting your local main branch in Git should be done with caution, as it is the primary development branch and typically the source of truth for your project. 
### Here's how to safely proceed:
1. Switch to a different branch: Git won't let you delete the branch you're currently on. Switch to another local branch or create a temporary one, for instance, git checkout develop or git checkout -b temp-branch.
1. Ensure all main commits are merged: If there are changes on your local main that haven't been merged into other branches (or pushed to a remote), you risk losing that work if you delete the branch without merging first. You can check for unmerged changes with: git status and for unpushed commits with git log origin/main..HEAD.
    1. Delete the local branch: Use the -d flag to safely delete a local branch only if it's been fully merged:
    ```sh
    git branch -d main

    ```
1. If the main branch is not fully merged, Git will prevent the deletion to avoid loss of data. If you are absolutely sure you want to delete main even with unmerged changes, you can use the -D flag (force delete). Be careful, though, as this could lead to data loss:
    ```sh
    git branch -D main

    ```
1. Verify the deletion: You can list your local branches to ensure the main branch no longer appears:
    ```sh
    git branch

    ```
