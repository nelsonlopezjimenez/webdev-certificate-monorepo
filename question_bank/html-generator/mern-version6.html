📥 Canvas Import Instructions

  1. Download the QTI Package: Click "QTI 2.1 Package" button above
  2. Navigate to Canvas: Go to your course → Settings → Import Course Content
  3. Select Content Type: Choose "QTI .zip file"
  4. Upload File: Select the downloaded .zip file
  5. Import: Click "Import" and wait for processing
  6. Review: Check the imported quiz in your course
