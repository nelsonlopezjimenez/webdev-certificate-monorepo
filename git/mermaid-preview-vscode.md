Yes — install the extension **"Markdown Preview Mermaid Support"** by Matt Bierner:

```
ext install bierner.markdown-mermaid
```

Then open any `.md` file and press `Ctrl+Shift+V` (or `Cmd+Shift+V` on Mac) to open the Markdown preview — Mermaid blocks render as diagrams automatically.

**Other useful Mermaid extensions:**

- **Mermaid Markdown Syntax Highlighting** (`bpruber.mermaid-markdown-syntax-highlighting`) — adds syntax coloring inside mermaid code blocks
- **Mermaid Editor** (`tomoyukim.vscode-mermaid-editor`) — dedicated editor with live side-by-side preview, useful if you're building complex diagrams

The first one (Matt Bierner's) is all you need for your README workflow.
